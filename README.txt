প্রিয় পণ্য অনলাইন — Android Studio project

এটি একটি প্রাথমিক Android WebView ডেমো প্রজেক্ট।
অন্তর্ভুক্ত: ক্যাটাগরি, পণ্য তালিকা, সার্চ, কার্ট, COD অর্ডার ফর্মের ডেমো।

APK তৈরি:
1. Android Studio ইনস্টল করুন।
2. এই ZIP Extract করে Android Studio-তে Open করুন।
3. Gradle Sync সম্পন্ন হতে দিন।
4. Build > Build Bundle(s) / APK(s) > Build APK(s) নির্বাচন করুন।

গুরুত্বপূর্ণ:
- এই সংস্করণে অর্ডার বাস্তবে সার্ভারে যায় না।
- Admin login, database, product upload, order management, payment gateway যোগ করতে backend/API দরকার।
- Play Store-এ প্রকাশের আগে privacy policy, app signing এবং বাস্তব পরীক্ষা দরকার।
